# Duck art provenance and rights

The five duck meshes, their UV layouts, deformation rig, animation curves and cosmetic meshes are original assets authored for this repository by the Blender Python program `scripts/art/build_ducks.py`. No downloaded mesh, photograph, paid asset or third-party texture was used. Natural feather and cosmetic color maps were generated specifically for this project with the built-in OpenAI image generation tool, using the original procedural UV maps as layout references where appropriate. Blender bakes the authored bump shaders into actual tangent normal maps. The user-supplied visual reference and approved generated concept guided anatomy, breed selection and art direction; neither reference picture is baked into these meshes.

Editable sources are in `art-source/*.blend`; each contains the full mesh, seven-bone skeleton, vertex weights, UVs, packed images, materials and idle/swim/celebrate NLA actions. Original generated PNG maps, derived runtime JPEG albedos and baked PNG tangent normal maps are retained alongside them. Runtime exports are in `public/assets/ducks/`. The script plus retained generated inputs reproduce these exports without another image generation request. Generation prompts and output provenance are recorded in `art-source/imagegen-prompts.md`. These original assets introduce no purchased asset fee or third-party asset attribution requirement.

Blender is a build tool, not a shipped runtime dependency. Portable Blender 4.5.3 was downloaded from the [Blender Foundation official distribution](https://download.blender.org/release/Blender4.5/blender-4.5.3-windows-x64.zip). Blender itself is [GNU GPL licensed](https://www.blender.org/about/license/); the GPL on the tool does not impose a GPL license on rendered images or original exported artwork. The portable tool/archive are ignored and are not committed.

## Fidelity boundary

These are original anatomical game models with a welded, subdivided continuous body/neck/head surface, curved closed feather vanes fitted to that surface, a shaped bill with nostrils/nail/seam, inset corneas, tarsi, toe geometry and web membranes. Mandarin has cheek markings, ruffs and elevated sail feathers; Runner has a narrower elevated torso and longer neck. The hat seats against the current skull through a surface query and includes straw weave, a navy band and a brass pin. They are not scanned animals: fine filaments are represented mainly by color and normal maps, and proportions/material response remain an interpretation of the reference. The supplied photographic concept is an art-direction target, **not evidence that these real-time meshes achieve identical photographic fidelity**. The Blender previews are actual renders of source geometry, not the concept image.

Only performance measured in the running application on named hardware can substantiate a frame-rate claim. The assets provide a lower-detail export to support such testing, but the asset pipeline alone does not establish 60 FPS desktop or 30 FPS mobile.
