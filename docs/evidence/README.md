Desktop capture is 1440 x 900; mobile capture is 390 x 844 with full-page scrolling. Mobile screenshots are browser viewport emulation, not physical-device qualification. Performance evidence is collected separately in `performance-latest.json` and `performance/` using real 30-second, 100-entry races across all five stages.

Visual review: the timber/charcoal/gold interface, rigged ducks, cosmetic meshes, stage content, swimming and wakes are implemented. Mountain shapes, shoreline density, architecture, feathers and lighting remain visibly less natural than the photographic reference. The screenshots make that gap reviewable; they are not a claim of full visual acceptance.

See [release verification](../release-verification.md) for test results, deployment identity, rollback and remaining acceptance work.
